inspired by https://www.youtube.com/watch?v=W2Xb2GFK2yc

using Bohmian trajectories to visualize the wavefunctions of atomic orbitals
only hydrogen (and other one-electron ions) has exact analytic solutions.
Everything past helium requires approximation.

### Quantums
- n: the principal quantum number, essentially the electron's energy level and shell. There's no upper limit on n in the theory.
